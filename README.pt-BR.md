# Changelog

Um projeto de craft: uma página de changelog para o Lumen, um produto fictício. Desenhada no Figma e no Pen, e construída com HTML, CSS e JavaScript puros, sem frameworks ou dependências.

[Read in English](README.md)

## Características

- Layout responsivo para mobile, tablet e desktop, fiel ao design original
- Filtro de releases por tipo e carregamento de releases anteriores sob demanda
- HTML semântico e acessibilidade WCAG AA: anúncios para leitores de tela, gestão de foco, suporte a teclado e contraste adequado
- Animações guiadas pela rolagem: o conteúdo surge ao entrar na tela e a linha do tempo se preenche conforme a leitura
- View transitions ao filtrar, além de uma entrada curta da página
- Melhoria progressiva: o conteúdo funciona sem JavaScript e as animações respeitam a preferência por movimento reduzido

## Rodando localmente

```sh
npm start
```

Depois abra http://localhost:4321. Requer Python 3.
