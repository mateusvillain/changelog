# Changelog

A craft project: a changelog page for Lumen, a fictional product. Designed in Figma and Pen, and built with plain HTML, CSS and JavaScript, with no frameworks or dependencies.

[Leia em português](README.pt-BR.md)

## Features

- Responsive layout for mobile, tablet and desktop, faithful to the original design
- Filter releases by type and load earlier releases on demand
- Semantic HTML and WCAG AA accessibility: screen reader announcements, focus management, keyboard support and readable contrast
- Scroll-driven animations: content reveals as it enters the screen and the timeline fills as you read
- View transitions when filtering, plus a short page entrance
- Progressive enhancement: content works without JavaScript and animations respect reduced motion

## Running locally

```sh
npm start
```

Then open http://localhost:4321. Requires Python 3.
